
# First Responder Standard Operating Procedure (SOP)

## Case Details
- Case Name: Case Omega
- Incident: Ransomware Attack on Healthcare Network
- Location: Fictional Omega Care Hospital
- Student: Vansh Sharma
- Roll Number: 2301730159

## 1. Incident Overview
A ransomware incident was reported at Omega Care Hospital on 18 November 2026. Multiple workstation files displayed unfamiliar extensions and a ransom note appeared on the affected system.

## 2. First Responder Procedures

1. Ensure the safety of patients and hospital staff.
2. Obtain authorization from the hospital administration.
3. Secure the affected area and restrict unauthorized access.
4. Avoid shutting down or restarting affected systems unnecessarily.
5. Isolate compromised systems from the network.
6. Photograph the affected workstation and surrounding environment.
7. Record system details, hostname, asset ID and logged-in user.
8. Identify potential digital evidence sources.
9. Preserve system, network and authentication logs.
10. Record connected USB devices and external storage.
11. Acquire forensic images using approved tools.
12. Calculate SHA-256 hashes of acquired evidence.
13. Maintain a Chain of Custody record.
14. Secure evidence in controlled storage.
15. Prepare an incident handover report.

## 3. Digital Evidence Identification

- Compromised computers
- Hospital servers
- Network logs
- Firewall records
- USB devices
- Browser history
- Login records
- Cloud access logs
- Backup records

## 4. Scene Documentation

The investigation scene is documented using:
- Photographs of affected workstations.
- A digital scene sketch.
- Evidence identification tags.
- Device and network connection details.

## 5. Evidence Preservation

All collected evidence must be preserved without modification. Original evidence should be stored securely, and forensic analysis should be performed using verified working copies.

## 6. Conclusion

The first responder procedure ensures proper incident handling, evidence preservation and documentation while minimizing disruption to hospital operations.

Note: This is a simulated academic investigation. No real hospital system was accessed.
